一、结论先行

你的框架最有希望形成的 Alpha，不是“发现好公司”，而是比市场更快、更一致地完成：下游变化 → 上游受益归因 → 财务兑现验证 → 预期差判断 → 风险受限的仓位表达。

建议把系统缩窄成一个明确赛场：“业绩/订单硬证据驱动的产业链传播策略”。题材热度、涨停、调研和研报只负责判断定价状态与确认，不再作为单独开仓理由。

当前 v2.0 的强项是产业链结构、反例意识、证据分级和固定复盘；缺口是把“研究上可信”误写成“资金上可押”。第二份报告正确指出了这个方向，但其中的 0.62 入池、0.25 Kelly、FCF 0.6、8%/12%/15% 回撤闸门等数字并未经过你的样本训练，不能称为概率或最优参数，只能作为待验证的起始草案。

最终系统应由三层组成：

Alpha 层

硬证据、产业链传播、盈利预期差、兑现质量。

状态层

业绩、题材、机构定价、流动性收缩四种状态及其概率。

资金层

基于预期损失、跳空、相关簇、流动性和回撤预算分配仓位。

本报告是系统研究与规则草案，不是个股推荐，也不承诺收益。所有标为“草案阈值”的数字必须经过点时点回放、影子运行和小资金阶段验证。

二、“十万到千万”的目标数学

10万元到1000万元是 100倍。不考虑新增资金、税费和中途取现，所需复合年化收益如下：

完成时间所需年化复合收益含义
5年151.2%几乎只能由极端集中、杠杆或巨大运气实现，破产风险极高。
7年93.1%远超可持续专业资金的常见区间。
10年58.5%需要长期顶尖 Alpha、极强顺风和极少重大回撤同时发生。
15年35.9%仍然非常困难，但比10年路径更具工程意义。

100倍不能作为模型优化目标。它会诱导回测选择高波动、高集中、高尾部风险参数。系统真正的目标函数应是“最大化长期几何增长，同时约束破产概率、最大回撤和不可交易风险”。截至2025年6月，SPIVA 对中国大盘主动基金的统计显示，1年、3年和5年跑输基准的比例分别为60.5%、69.6%和50.8%，这说明持续超额并非默认结果。[S1]

最重要的五个反例机制

  1. 好行业、坏股票：行业空间真实，但预期已透支或价值留在非上市主体。
  2. 毛利率假改善：原材料降价、汇兑、产品结构切换或业务并表造成改善。
  3. 硬证据假增量：订单金额大，但确认周期长、净利润贡献低、可取消或重复公告。
  4. 研究正确、交易错误：催化迟到、持有期不匹配、题材退潮或流动性收缩。
  5. 单股正确、组合失败：持仓表面分散，实际都属于AI算力/半导体设备等同一叙事簇。

四、问题一：我们如何获取超额收益？优势在哪里？

答案不是“信息更多”，而是公开信息被更快结构化、更好做因果归因，并且只在合适市场状态中用风险预算表达。

Alpha Engine A：业绩与订单的“证据时差”

2025年的中国市场研究发现，盈余公告前后存在漂移；机构和大额个人投资者在公告前更倾向于沿盈余意外方向交易，小额个人投资者则更常逆向并承受损失。公司业绩指引、分析师覆盖和机构调研会增加公告前漂移。[S2]

可交易优势：不要等“净利润同比100%”标题出现，而是提前维护订单、合同负债、客户资本开支、认证、价格/产量和卖方预测的点时点序列，计算市场尚未完全修正的盈利路径。

Earnings Wedge = 公司最新可见盈利路径 − 公告前冻结的一致预期/市场隐含路径

Alpha Engine B：产业链信息传播

清华2024年A股研究显示，基于客户关系的动量因子对未来收益具有预测力，但年度更新的供应链数据会削弱时效。该证据属于单篇硕士论文，强度有限，适合支持“需要验证的假设”，不适合作为直接实盘定律。[S3]

可交易优势：把“产业链卡位”改写成事件传播图：客户扩产/订单 → 具体产品 → 上市公司收入占比 → 认证与交付周期 → 毛利/现金流 → 估值预期。只有能量化经济暴露的边才进入交易决策。

Alpha Engine C：兑现质量而非毛利率崇拜

核心不再是单独的 GPM，而是四项联动：

增量毛利率

Δ毛利 / Δ收入，判断新增收入是否真正高质量。

现金转化

(经营现金流−资本开支) / 调整后净利润，识别利润表繁荣。

营运资本

应收、存货、合同资产的增速是否吞噬增长。

资本效率

新增毛利/新增投入资本，判断扩产是否创造价值。

Alpha Engine D：预期差，而不是“好公司”

每个标的都必须回答：“当前价格已经隐含了多少增长？”建议用反向估值建立三条路径：市场隐含、研究基准、证伪情景。没有预期差，就算公司质量很高，也只进观察池。

Alpha Engine E：把注意力当作状态变量

2025年研究显示，多指标合成的投资者注意力与A股异常收益有关；另一项跨中美研究发现，中国市场中零售驱动的信息扩散对股票间超额共动影响更强。[S4] [S5]

结论：热度不是买入信号；它负责两个动作：判断题材是否正在扩散，以及提高同叙事簇的风险惩罚。

5.2 六道开仓闸门

  1. 原始证据闸门：公告、定期报告、交易所问询回复、客户/供应商正式披露至少一项。只有研报/调研/热度不得开仓。
  2. 经济暴露闸门：必须估算对未来12个月收入、毛利或净利润的影响范围；无法归因则停留研究池。
  3. 预期差闸门：冻结事件前一致预期或反向估值路径；“公司很好”不等于有预期差。
  4. 时间闸门：关键证据预计在20—63个交易日内验证；更长周期另建“战略观察池”，不得占用交易仓位。
  5. 赔率闸门：草案要求上行情景/下行情景 ≥ 1.8，概率加权预期收益扣成本后为正。
  6. 组合闸门：单票、叙事簇、流动性、隔夜跳空预算和市场状态均不超限。

类别触发动作
硬否决立案/造假、审计非标、资金占用、实控人流动性危机、重大退市风险在首个可执行窗口退出；禁止补仓。

时间止损63个交易日内没有预定证据，且没有新证据延长时钟回研究池，不让“短期交易”悄悄变成长线套牢。
市场状态进入流动性收缩或簇风险升至极端按组合风险乘数降仓，不等单股逐一证伪。
操作纪律亏损后想改规则、临时扩大持有期、删掉反例冻结人工加仓，强制写决策偏差记录。

5.6 回撤闸门

先沿用第二份报告的 8%/12%/15% 作为待验证草案，但动作必须确定化：

  • 距高点回撤8%：新仓风险预算×0.7，暂停低证据等级候选。
  • 回撤12%：总风险仓位降至当时目标的一半，冻结所有参数优化。
  • 回撤15%：进入防守状态，仅保留证据A级、低簇相关头寸；完成归因前不得恢复。

阈值是否合理要用2018年以来的多状态历史回放检验。2024—2026可作为研究证据窗口，但仅两年多无法覆盖完整A股周期。

  5. P4 执行信号：价格、成交、涨跌停、滑点；只优化成交，不创造投资逻辑。

七、问题三：系统上下文需要什么？Harness 如何构建？

Harness 的目的不是让LLM“更会推荐股票”，而是确保每个结论都在正确时点、使用正确证据、经过确定性规则，并留下可复现记录。

决策纪律原始假设、证伪条件、下一证据、审批人、人工覆盖理由防止事后改写。

7.4 AI 与确定性代码的边界

AI可以做

  • 公告抽取、分类与对比
  • 产业链关系候选和反例搜索
  • 事实/管理层说法/判断分离
  • 生成证伪问题和下一证据
  • 研究报告初稿与历史案例检索

AI不得直接做

  • 改写原始数据或发布时间
  • 凭主观分数产生“概率”
  • 绕过风险闸门
  • 直接向订单网关写入指令
  • 在缺少原始证据时自动开仓

核心控制：LLM 只能产生“建议对象”；仓位、成交限制、回撤、簇上限和订单白名单必须由确定性代码计算；最终下单要求人工批准。若未来自动生成或下达交易指令，需遵守“先报告、后交易”等程序化交易要求。证监会规则自2024年10月8日实施，沪深交易所实施细则自2025年7月7日实施。[S10] [S11]

7.5 数据质量的“失败关闭”规则

  • 原始公告下载失败：不得用二手摘要提升至交易合格池。
  • 发布时间或版本冲突：进入人工校验队列，保留两个版本，不覆盖。
  • 一致预期缺失：允许研究公司逻辑，但证券结论标记为“不可定价”。
  • 板块/证券制度未知：不得回测成交或生成订单。
  • 特征无 known_at：只可用于当前研究，禁止进入历史回测。

九、问题四：后续如何迭代优化？

9.1 用“假设注册”替代“加指标”

每次迭代必须先登记：机制、数据、方向、适用状态、持有期、预期失败条件、唯一主指标。没有预注册，不允许在看完回测后修改故事。

实验字段示例
机制客户资本开支上调后，供应商盈利预期修正存在时滞。
观测客户公告/指引、供应商收入暴露、事件前冻结一致预期。
标签20日和63日行业中性超额；最大不利变动；公告日Gap。
分组按业绩/题材/机构/压力状态，行业和市值分层。
证伪样本外超额≤0；仅在单一行业或单一年份有效；成本后消失。

9.2 验证设计

  1. 历史范围：外部证据以2024—2026为主，但策略验证至少回到2018年；否则没有疫情、2022下行、微盘风格切换等多状态样本。
  2. 点时点：所有财务、公告、预测、成分股、ST状态和交易制度用当时已知版本。
  3. 可交易：模拟T+1、涨跌幅限制、停牌、涨跌停无法成交、实际费率、滑点、除权和退市。
  4. 走样本外：滚动训练/验证/测试；最终保留一段完全不查看的锁箱期。
  5. 多重检验：记录所有因子、阈值和模型尝试；使用Deflated Sharpe、PBO或FDR控制，不只汇报最优版本。
  6. 基准：同时比较沪深300/中证500/中证1000、行业中性组合、简单盈利修正因子和等权锚池。
  7. 反事实：比较“有AI/无AI”“有状态开关/无状态开关”“风险仓位/等权仓位”，证明收益来自哪里。

9.3 晋级门槛

阶段最低门槛失败后
研究 → 回测候选机制明确；数据可点时点；事件样本≥100；主要状态每类≥20补数据或放弃，不调整故事迎合结果。
回测 → 影子运行成本后样本外超额为正；多数滚动窗口同向；参数邻域稳定；无单一年份贡献>50%降为研究模块。
影子 → 小资金至少3个月或30个独立信号；数据SLA达标；实时报价/模拟滑点差异可解释修数据/执行，不优先修Alpha。
小资金 → 扩仓至少50个实盘决策；概率校准优于基准；实际回撤和滑点在预算内；无重大人工绕规则回到影子运行。

9.4 系统KPI

Alpha

20/63日超额、分组单调性、命中率、盈亏比、状态条件收益。

风险

最大回撤、Gap损失、簇损失、流动性折价、尾部集中度。

校准

Brier score、预测分桶与实际胜率、置信区间覆盖。

执行

滑点、成交率、涨跌停失败、ADV占比、信号到订单延迟。

数据

公告完整率、延迟、双源冲突、解析错误、未来数据事故。

纪律

人工覆盖率、未记录改参、违规加仓、时间止损执行率。

9.5 冠军—挑战者机制

生产系统一次只运行一个“冠军”版本；新模型、LLM提示词、因子和阈值只在挑战者环境中运行。月度委员会最多批准一个实质变更，并保留旧版本可回滚。RD-Agent(Q)展示了自动研究—实现—反馈循环，但它的CSI300实验和1日预测目标不能直接外推到你的63日基本面系统；可借鉴流程，不能借用收益结论。[S13]

十一、最终版“十条军规”

  1. 没有原始证据，不进交易合格池。
  2. 不能量化经济暴露，不把产业链故事变成仓位。
  3. 没有冻结的市场预期，就不能声称“超预期”。
  4. GPM只是一项兑现指标，不是定价权的充分条件。
  5. 调研、研报、热度、涨停只能确认或调节风险，不能单独开仓。
  6. 仓位由可承受损失决定，不由研究兴奋程度决定。
  7. 只因证据增强加仓，绝不只因价格下跌加仓。
  8. 同一叙事簇按一个风险源管理。
  9. 亏损期冻结参数；规则只在月度复审中变更。
  10. AI不能直连订单；所有决策可追溯、可回放、可证伪。
