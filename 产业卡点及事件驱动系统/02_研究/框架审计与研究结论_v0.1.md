# 框架审计与研究结论 v0.1

日期：`2026-07-16`  
输入：`原始文档/交易框架.md`、`原始文档/deep-research-report.md`、上一轮 v3.0 规则规格、2024—2026 官方规则/论文/开源项目  
结论用途：为 PRD 提供取舍依据，不是已验证交易规则。

## 一、结论先行

现有框架最值得保留的资产是：

- 产业链卡点作为研究入口；
- 证据驱动、事实/假设/判断分离；
- GPM 趋势作为“利润货币化”线索；
- 锚池、日/周/月节奏与反例复盘；
- 低换手、集中研究、提前写证伪条件。

现有框架最大的结构性问题是：

> 它把“找出值得研究的公司”与“形成可交易、可配仓、可退出的股票”混在了一起。

因此，本次不是 Serenity 1.0 到 2.0 的简单加权升级，而是把系统拆成五个独立但连续的判断：

`产业约束真实 → 利润传导真实 → 事件改变路径 → 当前价格未充分反映 → 风险和成交允许`

任一环缺失都不能进入 Trade-ready。

## 二、保留、降级、删除

| 原框架元素 | 裁决 | 原因 | 新位置 |
|---|---|---|---|
| 产业链卡点 | 保留并强化 | 是差异化研究入口 | 产品/环节/供应商/客户/替代路线证据图 |
| GPM 趋势 | 降级为核心子指标 | 受原料、结构、业务切换、汇率等影响 | 货币化模块，与增量毛利率、现金转化、周转拆桥 |
| ROE_YOY | 降级 | 低基数、杠杆和周期污染 | ROIC、现金质量、行业/生命周期中性变化 |
| 任一 A/B/C/D/E 入锚池 | 删除 | 混合结构、事件、注意力和价格 | Research Pool 与 Trade-ready 双门槛 |
| 调研 30 日 ≥3 次 | 改写 | 绝对次数缺乏公司/行业/月度基准 | 异常调研强度 + 披露时点 + 访问者质量 |
| 券商上调次数 | 改写 | 覆盖数、陈旧度和历史回填会失真 | PIT 修订、分歧、覆盖和公告前预期 |
| LLM 8 维总分 | 仅作研究整理 | 未校准分数不等于概率 | 模块化证据卡，不能直接定仓位 |
| 真卡点 15—20% | 删除 | 类别不能代替下行、相关性、流动性 | 损失预算与多重上限 |
| 大股东减持等单项否决 | 拆分 | 大多数是上下文信号 | 硬否决/软风险两层 |
| 涨停 × 锚池 | 降为 P1 | 易受不可成交与注意力拥挤影响 | 只做行为/时点确认，不作为核心 Alpha |
| 9 个 cron 并行 | 重构 | 重复拉取、源不稳定、信息过载 | 单一事件总线 + 增量管线 + 数据健康 |

## 三、外部研究的可用结论与边界

### 1. 供应链信息扩散值得研究，但不能直接复制论文收益

中国市场的行业级供应链可预测性研究支持“上下游信息可能渐进扩散”的方向，因此客户资本开支、产品价格、库存和交期可作为先行变量。[Market segmentation and supply-chain predictability](https://ideas.repec.org/a/bla/acctfi/v60y2020i2p1531-1562.html)

边界：论文样本、组合构造、交易成本和可获得数据与个人 A 股多头账户不同。系统需要验证的是“哪些边、在何种状态、以多大延迟有效”，不是预设供应链动量必然赚钱。

### 2. 业绩公告后漂移可成为事件支线

2024 年研究在 A 股中讨论了业绩意外、投资者注意力与公告后漂移，支持研究“公告前预期—公告内容—隔夜反应—后续漂移”。[Post earnings announcement drift](https://www.sciencedirect.com/science/article/abs/pii/S1057521924003922)

边界：论文报告的组合结果不能作为本系统目标收益；需要按公告发布时间、涨跌停、下一可交易价格、流动性和成本重新验证。

### 3. 调研密度必须异常化

2025 年 JFQA 论文使用深交所公司访问数据，发现异常频繁访问与未来收益和基本面改善相关，且效果集中于被忽视、低成交量公司。[Investor Corporate Visits and Predictable Returns](https://www.cambridge.org/core/journals/journal-of-financial-and-quantitative-analysis/article/abs/investor-corporate-visits-and-predictable-returns/77C958598BB1DC92C46EA32BF252A4B9)

对本系统的含义：调研是发现/确认信号，不是固定次数门槛；需按公司历史、行业、月份、参与机构与披露时间标准化，并防止价格上涨后的跟随调研被误判为领先信息。

### 4. PIT 是不可妥协的数据要求

Qlib 文档明确指出财务数据会修订，使用最新版本进行历史回测会造成泄漏。[Qlib PIT](https://qlib.readthedocs.io/en/stable/advanced/PIT.html)

对本系统的含义：`available_at <= decision_at` 是查询层硬约束；只有日期、无时间的数据默认在下一可交易时段生效，并标记时间质量。

### 5. 自动研究框架可以借鉴，但 Agent 不拥有资金权限

[RD-Agent](https://github.com/microsoft/RD-Agent)展示了因子—模型共同迭代的研究自动化方向；[Qlib](https://github.com/microsoft/qlib)覆盖研究、回测和实验；[vn.py](https://github.com/vnpy/vnpy)提供事件引擎、paper account、组合与多种国内证券接口。

对本系统的含义：三者可作为参考或组件候选，但不能替代数据授权、A 股真实成交、独立风险和人工批准。Agent 只输出 ResearchProposal，不输出 Order。

### 6. 多次试验必须校正

不断修改指标和参数会系统性抬高最佳回测表现。Deflated Sharpe Ratio 的研究针对选择偏差、多重试验与非正态收益修正性能膨胀。[The Deflated Sharpe Ratio](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=2460551)

对本系统的含义：所有失败实验和参数都要记录，正式结论需要冻结样本外、稳健性、消融和多重检验审计。

## 四、需求层面的五项关键改变

### 1. 从“评分”改为“门槛 + 证据图 + 情景”

现阶段没有足够标注样本把主观分数校准为真实概率。任何 Logistic 系数、0.62 阈值或 Kelly 胜率如果没有训练/验证依据，都只能是研究假设，不能进入资金层。

### 2. 从“锚池”改为状态机

Research Pool 只表示值得继续研究；Trade-ready 才表示证据、赔率和风险均通过。`ABSTAIN` 是正常且重要的输出，不是系统失败。

### 3. 从“静态 GPM”改为利润传导桥

至少拆分：价格、销量、产品结构、原料/成本、产能利用率、汇率/补贴、一次性会计影响，并检查增量毛利率、CFO/净利润、FCF、应收与存货。

### 4. 从“高分配高仓”改为“先算会亏多少”

目标仓位应取单票、叙事簇、流动性、跳空、状态和回撤上限的最小值。只有新证据增强才允许加仓，价格下跌本身不是证据。

### 5. 从“研究脚本”改为可审计运行链

原始证据、解析、特征、状态、目标组合、模拟成交、对账和复盘必须由稳定 ID 和版本串起来。任一环无法回放，就不能进入下一发布阶段。

## 五、首个 MVP 研究切片

推荐先只做两条事件线：

1. 业绩预告/快报/财报：验证主营驱动、预期差、公告后反应与漂移。
2. 订单/中标/投产/量产/认证：验证产业卡点、收入与毛利传导、兑现窗口。

原因：两条线与原框架优势最贴近，原始公告可追溯，能够构建正反例，也足以暴露 PIT、去重、金额口径、公告时间、不可成交和情景定价问题。题材连板、热度和龙虎榜暂列 P1，避免同时解决研究优势与短线执行两类问题。

## 六、研究裁决

当前材料不是一套可直接实盘的系统，而是一套质量较高、带反例意识的研究原型。升级路径不应继续追求更复杂总分，而应先证明：

1. 产业卡点能否稳定转化为上市公司增量利润；
2. 哪类事件提供可交易的时间窗口；
3. 当前价格是否留有成本后赔率；
4. 在不可成交、相关性和回撤约束下，组合是否仍有样本外超额。

只有四项同时成立，“产业卡点及事件驱动系统”才从研究框架变成交易系统。
