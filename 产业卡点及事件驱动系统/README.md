# 产业卡点及事件驱动系统

项目状态：`需求决策已确认 / v0.2 待文档验收；规则规格待编写`  
基线日期：`2026-07-22`  
市场范围：`中国 A 股`  
当前边界：`研究、回测、paper/shadow；不接自动实盘`

## 系统一句话定义

先找到产业链中供给响应慢、替代困难且利润可能向上市公司传导的关键约束，再用可核验事件确认盈利路径、预期差和时点，最后通过组合风险预算决定是否交易、交易多少和何时退出。

## 目录

- `01_需求/`：产品需求、目标、边界、验收标准、待确认决策。
- `02_研究/`：框架审计、外部证据、来源登记与研究假设。
- `03_规则与规格/`：下一阶段的状态机、字段、信号和风险规则。
- `04_数据/`：数据源、PIT 契约、快照、质量与血缘。
- `05_实现/`：研究引擎、事件管线、回测和 paper 执行实现。
- `06_测试与验证/`：golden cases、回放、样本外、压力与偏差测试。
- `07_运行与复盘/`：每日/每周操作手册、决策日志和版本发布。

## 推荐研发顺序

`需求冻结 → 事件与证据规格 → 数据契约 → 最小可回放管线 → 规则回测 → paper/shadow → go/no-go`

首个实现切片不做全市场自动交易，只打通一条可审计链路：

`订单/合同及其前置公告 → 原文存档 → E3/E3.5/E4 解析 → 产业卡点匹配 → 四道门 → 情景与风险 → ABSTAIN/候选 → 首次可成交回放`
