# 题材轮动独立立项评估 v0.1

日期：`2026-07-23`  
状态：`independent_research / requirements_not_started`  
项目名称：`题材扩散与资金轮动系统`  
边界：本文是独立研究项目的初始立项评估；建档不等于证明存在可交易 Alpha，也不修改产业卡点系统的 PRD 或交易门槛。

## 一、结论先行

**建议分开研究和建模，但共享底层平台与组合风险。** 当前系统研究的是“产业约束与硬事件如何传导为利润、现金流和预期差”；题材轮动研究的则是“共同注意力与资金如何从触发点向龙头、跟随股扩散，随后因拥挤或信息证伪而衰减”。两者可能交易同一只股票，却不是同一收益机制，也不应共用入场、退出、持有期或 Alpha 归因。

用户观察到的“商业航天（2025-12—2026-01）、电力（2026-02）、光模块与半导体（2026-04—06）”目前仅登记为 `USER_OBSERVATION`。在逐日重建当时的题材名称、成分、首次可得信息和可成交价格之前，不认定这些阶段划分正确，更不能据此反推规则。

## 二、为什么不是现有系统的一个买入模块

| 维度 | 产业卡点及事件驱动系统 | 题材扩散与资金轮动研究 |
|---|---|---|
| 经济链 | 产业约束 → `E4` 硬承诺 → NTM 利润/现金流 → 预期差 | 叙事或事件触发 → 共同注意力/买压 → 龙头—跟随扩散 → 拥挤/反转 |
| 关键证据 | 公告、合同、采购、财报、产业上下文 | PIT 题材词、成分变化、广度、换手、涨停/开板、龙头—跟随图、注意力 |
| 入场资格 | `E4_public` 且 Gate 1—4 全部通过 | 待验证的点火/扩散状态；不能借用 `E4` 资格 |
| 退出依据 | 证据、价值、风险、验证时钟 | 广度失速、龙头破坏、扩散失败、拥挤耗尽及风险 |
| 主要周期 | 暂定最长 120 个交易日 | 预计更短且状态依赖，需单独估计 |
| 最大偏差 | 利润桥错误、事件已定价 | 事后命名题材、追涨不可成交、把行业/小盘 Beta 当 Alpha |

原始研究支持“注意力扩散”是一种可与基本面共同冲击区分的候选机制：A 股共同注意力与收益共振相关，且在低机构持股公司更明显；同名股票会在缺乏真实经济关系时发生信息外溢；行业龙头业绩也可能被投资者过度外推给同行，之后在同行自身公告时纠正。[共同注意力研究](https://doi.org/10.1016/j.najef.2021.101548)、[同名股票研究](https://doi.org/10.1016/j.jcorpfin.2021.102015)、[龙头信息过度外溢研究](https://doi.org/10.1111/acfi.70003)

这只证明“机制值得检验”，不证明追逐热点可获利。基于涨跌停次数的注意力研究发现，高关注买压随后对应较低收益；中国行业层面同时存在中期动量与短期反转的历史证据，方向取决于周期、行业结构和控制变量。[涨跌停注意力研究](https://doi.org/10.1016/j.irfa.2022.102265)、[中国行业动量研究](https://doi.org/10.1080/1540496X.2016.1264248)

## 三、架构裁决：策略分离，平台共享

### 3.1 必须隔离

- `strategy_id`、虚拟账本、股票池、状态机、信号、参数、基准、回测、P&L 和复盘分别版本化。
- **MVP 每笔真实或影子交易只能有一个主 `strategy_id` 和一个收益归因所有者。** 同一证券同时被两个系统选中时，另一个系统只能添加上下文标签，不能重复认领收益。
- 两个策略分别通过样本外与前瞻验证；任何一方失败不能由合并组合掩盖。
- 题材系统不得用现有产业上下文为事后成分标签；现有系统也不得用题材热度代替公司级经济义务。

### 3.2 可以共享

- 原始公告与行情归档、PIT 时钟、证券主数据、公司行动和历史交易规则；
- 涨跌停、T+1、停牌、滑点、冲击与容量仿真；
- 组合现金、风险簇、同源催化暴露、回撤停机、人工审批和不可变审计。

### 3.3 单向接口边界

当前产业系统最多接收 `theme_regime` 和 `crowding_state`，用途仅限：

1. 补充 Gate 3 的“是否已被题材热度提前定价”判断；
2. 收紧风险预算、流动性假设或 `ABSTAIN` 条件。

它们**不得把 `E0—E3` 升级为真实仓位，不得放宽 `E4_public`、Gate 2 的利润重要性、Gate 3 的预期差或 Gate 4 的可成交赔率，也不得单独产生 `TRADE_READY`**。

## 四、待证伪的最小状态机

以下只是 `hypothesis`，不能直接实现为交易规则：

`LATENT → IGNITION → DIFFUSION → CROWDING → EXHAUSTION → COLLAPSE/RECYCLE`

- `LATENT`：题材词与候选成分已能在当时被识别，但广度和异常成交尚低。
- `IGNITION`：可追溯触发器出现，题材内异常收益、成交或注意力开始同步抬升。
- `DIFFUSION`：龙头先行后，新增上涨/涨停/放量成分扩大；必须优于同业与伪题材对照。
- `CROWDING`：交易集中、换手或关注过热，边际扩散变弱；此状态可能是减仓而非加仓信号。
- `EXHAUSTION`：龙头创新高失败、广度背离、开板或负扩散显著增加。
- `COLLAPSE/RECYCLE`：扩散链断裂，或在新公开触发器下重新进入独立一轮生命周期。

状态转换必须使用当时可得变量和预注册阈值；禁止用完整行情路径标注“真正龙头”“主升浪”或“退潮日”。

## 五、PIT 数据最低契约

每个题材及成分至少保存：

~~~text
theme_id, theme_name_as_of, narrative_terms_version,
source_id, source_published_at, first_seen_at, available_at,
member_id, membership_reason, valid_from, valid_to, confidence,
economic_link_type, leader_candidate_as_of,
price_limit_rule_version, security_status,
return, turnover, amount, limit_hit, limit_close, open_board,
breadth, new_high_breadth, attention_proxy, data_snapshot_id
~~~

关键约束：

- 不得用今天的“概念板块成分”回填历史；每次加入、剔除和改名都需 `valid_from/valid_to`。
- 题材成员应区分 `economic_link`、`disclosure_link`、`name/salience_link` 与 `unknown`，避免把同名、蹭热点或媒体共现当产业关系。
- 日线无法证明盘中可成交时，信号顺延；一字涨停、无卖盘和停牌的理论收益记为不可实现。
- 中证主题指数方法说明了主题样本会经过业务筛选、流动性筛选与定期调整，可作稳定代理池，但不等于当时市场正在交易的题材，也不能替代逐日题材成员快照。[中证数据要素主题指数编制方案](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/932028_Index_Methodology_cn.pdf)

## 六、最小研究问题

1. **发现**：仅使用 `available_at <= decision_at` 的信息，能否在价格主升段前稳定识别题材，而非事后命名？
2. **扩散**：龙头—跟随的方向和时滞是否稳定优于行业、经济关系和随机网络对照？
3. **可交易性**：扣除首个可成交价、T+1、涨跌停、停牌、费用、滑点和容量后是否仍为正期望？
4. **独立性**：收益是否只是行业动量、小微盘、成长、高换手、极端收益或市场风险暴露？
5. **退出**：广度、龙头结构和拥挤变量能否在样本外减少回撤，还是只会过度交易？
6. **容量与互补性**：该策略在 10 万—30 万元规模下能否执行，且是否在组合层提供产业系统之外的增量收益/分散，而非重复风险？

## 七、冠军挑战与替代解释

| 基线 | 必须回答的问题 | 推翻条件 |
|---|---|---|
| `B0 market/industry` | 是否只是市场或申万/中证行业行情 | 行业中性后收益消失 |
| `B1 simple industry momentum` | 复杂题材图是否优于简单行业相对强弱 | 样本外扣费后不优于简单模型 |
| `B2 size/style/turnover` | 是否只是小盘、成长、高波动、高换手 | 中国本土规模/价值及流动性控制后消失 |
| `B3 limit-hit continuation/reversal` | 是否只是涨跌停延迟发现或短期反转 | 首次可成交后无收益，或由涨跌停基线完全解释 |
| `B4 fundamental/common news` | 是否只是同一政策、盈利或硬事件共同冲击 | 控制共同事件后扩散不再存在 |
| `B5 pseudo-theme/placebo` | 是否可从任意相关词或随机成分“挖出”轮动 | 伪题材取得相近表现 |

中国特定规模与价值因子可解释大量既有异常，且最小市值“壳价值”会扭曲常规规模因子，因此至少应采用中国本土因子并做剔除最小 30% 股票的稳健性检验。[Size and Value in China](https://doi.org/10.1016/j.jfineco.2019.03.008)

价格限制必须单独归因。创业板涨跌幅放宽的准自然实验显示，放宽限制改善了价格发现；这意味着涨停后的延续既可能是信息扩散，也可能只是制度造成的延迟，不能自动归给题材机制。[价格限制与价格发现研究](https://doi.org/10.1016/j.jempfin.2023.05.003) 当前上交所规则还明确股票涨跌幅限制、买入证券交收前不得卖出等约束；历史回测必须按当时有效版本，而非套用 2026 规则。[上交所交易规则（2026 年修订）](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml)

## 八、建议的验证门槛

以下数值是待确认的 `validation_hypothesis`，目的是防止少数热点和多重试验制造假阳性：

1. **PIT 门**：正式信号的 `available_at`、题材版本、历史成员和历史交易规则字段完整率 100%；无法重建者只能 `ABSTAIN`。
2. **样本门**：至少 30 个相互独立且已结束的题材生命周期，同时至少 30 笔真实可成交、已结束的交易；任一关键子组少于 15 个只作描述，不作有效性结论。
3. **增量门**：复杂模型必须在冻结样本外、扣费后稳定优于 `B0—B4` 中表现最好的简单可执行基线；按题材/时间风险簇重采样后，平均超额收益 95% 置信区间下限大于 0。
4. **集中度门**：最大单一题材贡献不超过总净利润 25%；结果需跨年份与不同主题族成立，而非依赖用户已观察到的几个赢家。
5. **过拟合门**：登记全部词典、窗口和阈值试验，报告参数邻域、消融以及 PBO/Deflated Sharpe 或等价审计；Deflated Sharpe 专门校正多重选择、非正态与样本长度偏差。[Deflated Sharpe Ratio 原始论文](https://doi.org/10.3905/jpm.2014.40.5.094)
6. **前瞻门**：规则冻结后 `forward_shadow` 至少 6 个月且不少于 10 个合格信号，两项取更晚；未通过前不得使用真实资金。

若只证明 `theme_regime/crowding_state` 能降低产业系统的追高和回撤，却不能独立产生扣费后 Alpha，则不升级为独立收益引擎，只保留为共享风险上下文。

## 九、推荐研发顺序

1. 先冻结现有产业系统的 Alpha 竞争设计，避免两个研究同时改写标签和成功标准。
2. 在本项目 `02_研究/` 内建立题材研究章程、PIT 可得性审计和少量正/负回放，不立即建设规则或实盘系统。
3. 用用户列举的月份做 `golden observations`，同时加入未持续、假突破、快速反转和无明确题材的负样本。
4. 只有数据可重建、独立机制和首个可成交后收益三项均过门，才升级到规则规格与实现阶段。

## 十、证据局限

- 上述论文给出的是历史平均关系，不保证 2024—2026、特定题材或个人投资者可复制；部分结果依赖专有搜索、账户或论坛数据。
- “共同注意力”“行业动量”“涨跌停注意力”都不是完整的题材生命周期定义，不能直接拼成交易规则。
- 主题指数是规则化投资池，不是市场叙事的实时真值；商业数据商的概念标签若无历史版本，同样存在后见偏差。
- 多数论文报告长短组合或理论成交，当前项目首版只允许 long-only；必须重做可成交、容量和成本测试。
- 用户列举的阶段尚未做 PIT 回放，因此本文不评价其日期、题材边界或收益是否准确。
