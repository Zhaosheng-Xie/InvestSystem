# 题材扩散与资金轮动系统

项目状态：`独立研究已建档 / 需求未冻结 / 不允许实盘`  
基线日期：`2026-07-23`  
市场范围：`中国 A 股`

## 一句话定义

研究共同注意力和资金如何围绕题材触发器，从龙头向跟随股扩散，并在拥挤、扩散失败或证伪后衰减；不预设该机制能够产生扣费后 Alpha。

## 目录

- `06_测试与验证/`：冠军挑战、偏差测试、样本外和前瞻验证。

## 与产业卡点系统的边界

两套系统可以共享原始 PIT 数据、成交仿真和组合风险层，但必须分别维护 `strategy_id`、状态机、规则、回测和 P&L。题材状态只能作为产业系统的 Gate 3 或风险上下文，不能替代 `E4`、利润重要性和可成交赔率。
