# 题材扩散与资金轮动系统

- 项目状态：`独立研究已建档 / deferred / 需求未冻结 / 不允许实盘`
- 基线日期：`2026-07-23`
- 市场范围：`中国 A 股`

## 一句话定义

研究共同注意力和资金如何围绕题材触发器，从龙头向跟随股扩散，并在拥挤、扩散失败或证伪后衰减；不预设该机制能够产生扣费后 Alpha。

## 目录

- `01_需求/`：研究目标、交易边界、成功标准和明确不做什么。
- `02_研究/`：竞争假设、PIT 可得性、正负案例与证据。
- `03_规则与规格/`：待验证的状态机、信号、归因和风险规则。
- `04_数据/`：输入契约、PIT 要求、历史题材词典、成员版本、行情、注意力与血缘规格；不承担上游原始数据采集。
- `05_实现/`：发现、回放、回测和影子运行实现。
- `06_测试与验证/`：冠军挑战、偏差测试、样本外和前瞻验证。
- `07_运行与复盘/`：仅在验证通过后编写运行手册与复盘模板。

## 与产业卡点系统的边界

默认裁决是两套策略之间**零策略信号互通**：题材状态不得改变产业事件、门槛、候选、仓位或决策，产业状态也不得改变题材策略的入场、退出和归因。

两套策略可以分别引用同一个 InvestmentResearchKB Published Release，也可以复用经过版本化和独立测试的纯执行/市场规则库；除此之外，不得共享策略运行状态。每套策略必须分别保存并验证自己的：

- `strategy_input_ref`、Release 接收回执和 `StrategyRunManifest`；
- 状态机、规则版本、参数、候选集和决策记录；
- 虚拟或真实账本、持仓、归因和 P&L。

不得共享 KB 或任一策略的 raw、staging、SQLite、迁移目录、可变策略缓存和运行文件。两套策略可以只读复用 InvestSystem 内部 provider-neutral、内容寻址且不可变的已验证 Release 缓存，但各自仍须独立保存输入引用、消费回执和 Manifest，并验证引用的精确字节身份。任何共享库或共享缓存元数据都不得包含题材或产业的信号、标签、Gate 判断、决策状态或 Alpha 归因。

`theme_regime`、`crowding_state` 目前不得进入产业策略 Gate 3 或风险上下文。未来如需建立这类依赖，必须另行通过 ADR 批准，定义版本化契约，并对受影响的产业策略重新完成验证；在此之前默认拒绝该输入。

[题材轮动独立立项评估 v0.1](02_研究/题材轮动独立立项评估_v0.1.md) 中关于“共享底层平台与组合风险”以及向产业 Gate 3 提供题材状态的内容，仅保留为当时的研究假设，尚未获批，不是当前架构或生效规格。

本项目是独立的 `deferred` 研究轨道，不以产业系统 Stage 7 成功为前置条件，也不会随产业系统阶段自动启动。启动需求冻结、实现或验证，均需基于本项目自己的数据可得性、完成门和明确批准。
